*NLP Foundations · Post 3/4*

## What this post is

Notes from the text classification session. The classical pipeline — preprocessing, vectorisation (BoW / TF-IDF), classifier, evaluation — is still the foundation for understanding why modern fine-tuned transformer classifiers behave the way they do.

  📓 <strong>Format note:</strong> this post is my original handwritten notes, scanned and embedded
  below. If you want the modern, typed version with code and diagrams, the
  <a href="/blog/ml-foundations-01-what-machine-learning-actually-is">ML Foundations</a>
  series is the polished equivalent — the NLP series will get the same treatment later.
</Callout>

## Key takeaways (so you can scan)

- **Bag-of-words** loses order but keeps content; surprisingly competitive for many classification tasks.
- **TF-IDF** down-weights words that appear everywhere and up-weights words that appear in fewer documents.
- Evaluation metrics matter more than the model: F1, precision/recall, and class balance decide what "good" means.
